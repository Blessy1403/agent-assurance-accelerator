# Glossary

FNOL - First Notice of Loss

Underwriting - Process of evaluating insurance risk.

Settlement - Amount paid by insurer.

Claim - Request made by policyholder.

Policy - Insurance agreement.

Deductible - Amount paid by customer before insurance coverage starts.

Fraud Detection - Identifying potentially fraudulent claims.

RAG - Retrieval Augmented Generation.

LangGraph - Framework for building agent workflows.

Pydantic - Data validation framework.
